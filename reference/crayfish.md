# Crayfish RNA-Seq dataset

A dataset containing the dated phylogeny, raw counts, gene lengths and
sight condition for 17 species od Crayfishes.

## Usage

``` r
crayfish
```

## Format

A list, with:

- tree:

  Dated species tree

- counts:

  RNA-Seq count data

- lengths:

  Gene lengths

- sights:

  Wether a species can see (1) or is blind (0)
