# Log likelihood of a \`PhyloMArrayLM\` object

Log likelihood of a \`PhyloMArrayLM\` object

## Usage

``` r
log_likelihood(object)

# S4 method for class 'PhyloMArrayLM'
log_likelihood(object)
```

## Arguments

- object:

  an object of class
  [`PhyloMArrayLM`](https://pbastide.github.io/phyloDE/reference/PhyloMArrayLM-class.md).

## Value

log likelihood of the fitted linear model on all the genes
