# phyloDE

Functions to test for differential expression between conditions at the
tip of a phylogeny, combining Phylogenetic Comparative Methods
implemented in [`phylolm`](https://CRAN.R-project.org/package=phylolm)
with moderated statistics tailored for gene expression implemented in
[`limma`](https://bioconductor.org/packages/limma/).

## Installation

The development version can be installed from GitHub using the `remotes`
package:

``` r

install.packages("remotes")
remotes::install_github(repo = "pbastide/phyloDE")
```
